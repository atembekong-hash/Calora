Test only a small representative set of ordinary Coach interactions.

---

8. Live rollback checks

While the single-account activation is live, verify the reviewed rollback controls one at a time.

Confirm:

cohort removal blocks new Fact Context requests;

consent revocation blocks new Fact Context requests;

operational global kill blocks Fact Context;

restoring the approved one-account state works deterministically.


Avoid unnecessary repeated production toggling.


---

9. Automatic rollback triggers

Immediately restore deny-all if any of these occur:

more than one account becomes eligible;

consent bypass;

cross-account data exposure;

unauthorized fact leaves the approved boundary;

Legacy context reaches Fact Context provider egress;

stale response settles after invalidation;

nonce replay succeeds;

duplicate provider request occurs;

rollout cannot be disabled promptly;

provider output bypasses response validation;

privacy-sensitive information appears in logs;

unexpected database or authorization behavior;

repeated unexplained Fact Context errors.


Any cross-account or unauthorized-data issue is an immediate STOP condition.


---

10. Final state

If the controlled activation passes:

leave only the single authorized account eligible;

leave no broader rollout enabled;

record the exact active configuration.


If any rollback trigger occurs:

global rollout OFF;

cohort empty;

consent revoked/cleaned as appropriate;

Fact Context unavailable;

Legacy Coach remains available.
