# Calora Visual Forensics 01 — Root Cause

## Scope and baseline

This forensic pass began from protected `main` commit `f2a9d9eda183e944a8b2426f104c6f2291805a3a` (the merged unified-experience redesign). It reviewed the approved reference composites supplied by the owner, the merged redesign source, shared palette and modal primitives, every affected route group, and the configured test harness. No mobile build, production deployment, data change, or credential access occurred.

## What was ruled out

The theme provider selects an in-app palette and is not a light-only static stylesheet. The principal defect was therefore not a stale dark-mode branch: it was a light secondary-text token that failed ordinary-text contrast plus inconsistent role usage. A stale device binary remains possible only until the owner verifies a new client installation; no claim of physical-device validation is made here.

## Remediation principle

The repair centralizes semantics instead of applying arbitrary per-screen colors: ordinary text, muted text, links, disabled text, status foreground/tint, controls, sheet overlays/handles, and card/hero surfaces each have explicit roles in both palettes. Existing data, identity, navigation routes, persistence, health integration, subscriptions, and privacy controls are not changed.
