2. FIX ALL NUMBER FORMATTING AND LONG DECIMAL VALUES

Raw floating-point values are currently leaking into the visible interface.

This is unacceptable for a consumer nutrition application.

The underlying calculations may retain full precision internally, but the UI must NEVER expose raw floating-point precision like this.

Create or use a centralized number-formatting system instead of manually fixing individual screens.

Calories:
2050 kcal

148 kcal

Macros:

Percentages:

Important requirements:

- Format values only at the presentation layer unless the architecture already has an appropriate formatting layer.
- Avoid inconsistent formatting between screens.
- Use locale-aware thousands separators where appropriate.
