## 1. Test architecture

The test harness owns the complete sequence in one process:

1. Create a fresh synthetic external identity.
2. Establish real consent, global rollout, and reviewed cohort membership in
   the development database.
3. Start an authenticated Fact Context route request.
4. Wait for an explicit provider-entry promise, proving authorization passed
   and the provider call is pending.
5. Change exactly one rollback control.
6. Release the held provider promise.
7. Await the HTTP response and assert the post-provider authorization fence.
8. Assert one provider invocation and clean up all synthetic state.

No detached clients, shell background jobs, timing-only races, or production
processes were used. The provider transport and bearer verification were
controlled in-process; the consent, rollout, cohort, idempotency, and
post-settlement checks were real route/database behavior.

The test is fail-closed for environment safety. It requires:

- `NODE_ENV=test`;
- explicit `COACH_FACT_CONTEXT_SYNTHETIC_REHEARSAL=development-only`;
- database name `heliumdb`; and
- PostgreSQL system identifier `7670770438921318420`.

The check runs through the same pool used by the database client before any
test setup write. Production was identified separately as `neondb` on cluster
`7670939736220280207`, which is not allowlisted.

## 2. Synthetic identity and environment

## 4. Stale-completion and Legacy Coach behavior

All four cases settled through the route’s post-provider fence. The fence
rechecks:

- the process-local server gate;
- current cohort rollout eligibility; and
- current server-owned consent.

Invalidated completions were discarded rather than returned as Fact Context.
The harness observed no client Fact Context delivery for these rejected
responses. Existing Calora lifecycle tests additionally prove stale-result
suppression and that a Fact Context selection does not automatically retry
through Legacy Coach.

No Legacy Coach fallback request or response was generated by the pending
rollback cases.
